# 话务中心高保真原型
## 入口
- 根目录 `index.html` 会自动跳转至话务中心工作台。
## 页面清单
- `03-高保真页面/话务中心/话务中心工作台.html`：话务员事件接收、判别、沟通、挂起与任务派发主流程，支持收起事件队列，并按当前事件切换区域巡查地图和资源模拟数据；选中事件后可通过地图右上角人员图标按需显示当前项目在线人员位置，默认关闭，不区分人员状态，点位展示岗位、距事件距离与定位时间，并与资源派发地图复用；用户开启后，该图层在当前工作台会话内跨事件保留，只有主动关闭才隐藏；资源派发复用工作台右侧栏，默认展示推荐人员，也可自主按姓名、组织、岗位或车牌搜索当前项目的人员和车辆资源；地图持续展示推荐资源、检索结果与选中资源至事件的路线预览和 ETA；语音选择默认使用弹窗，打开时预选巡查上报人，其他成员按当前项目组织分类并支持按姓名、项目、组织或岗位搜索；群组通话采用成员卡片网格，会中可继续添加/移除成员、管理单人麦克风或对其他成员全员静音，并可收起为地图悬浮通话条。事件图片预览提供补充信息、派发任务和标记无效操作，其中补充与无效表单在图片右侧展开，派发任务复用右侧资源派发流程。已完成任务详情为只读，不显示补充、派发、标记无效、更多、语音通话、挂起或通话记录回拨操作。
- `03-高保真页面/话务中心/后台任务明细.html`：从工作台右上角“后台管理”进入的事件记录明细后台页，首屏直接提供查询和列表操作，支持按项目名称、车牌号、关联巡查员、话务员、发生时间和处理状态查询；列表支持勾选、分页、导出所选记录，并通过详情弹窗查看事件、补充和派发信息，以及位于右侧、按事件顺序排列的结构化操作时间轴（日期、时间、操作人、操作行为）。
- `03-高保真页面/话务中心/无待办事件.html`：任务接收关闭或暂无事件的空状态。
- `03-高保真页面/话务中心/派发处理中.html`：任务派发等待状态。
- `03-高保真页面/话务中心/接收关闭确认.html`：关闭任务接收的确认状态。
## 公共组件
- `03-高保真页面/话务中心/assets/common.css`：公共 Ant Design 风格变量、头部、按钮、标签、弹窗和表单样式。
- `03-高保真页面/话务中心/assets/common.js`：弹窗、提示和任务接收开关的静态交互。
- `03-高保真页面/话务中心/assets/vendor/leaflet/`：本地 Leaflet 地图库，用于事件点选、巡查车位置、巡查轨迹、巡查上报范围和地图缩放；底图通过 OpenStreetMap 在线瓦片加载，因此预览环境需要可访问互联网。
## 最近变更
- 2026-08-10：待处理事件改为由话务员显式点击“开始处理”接单；接单后记录并展示处理人和接单时间，才开放后续处理操作。挂起事件继续归原处理人，本版本不支持话务员间移交或释放。
