## 1. 业务背景与使用角色
### 1.1 业务背景
话务中心面向话务员，以事件为中心接收巡查人员通过车辆套件上报的事件。话务员查看证据、判别和补充信息；存在疑问时发起沟通或挂起；确认有效后分配处置资源。已派发事件同步至环卫云平台动态任务跟踪。当前范围仅处理车载监控采样事件，话务中心视角的事件发现类型统一记为人工。
### 1.2 使用角色
| 角色 | 职责 | 数据范围 |
| --- | --- | --- |
| 话务员 | 接收事件、核实判别、补充信息、发起沟通、挂起、分配资源、查看后续流转。 | 已分配或推送至本人处理范围的车载监控采样事件；具体范围待确认。 |
| 任务接收人/处置人员 | 接收环卫云动态任务并现场处置。 | 非本模块直接操作角色。 |
### 1.3 核心目标与价值
| 目标维度 | 说明 |
| --- | --- |
| 及时接收 | 让待判别、待分配阶段的事件进入话务员队列并按优先级呈现。 |
| 快速判别 | 以事件证据和沟通结果支持有效/无效判断及信息补充。 |
| 高效分配 | 基于责任区域、距离和任务量推荐可用资源，并支持人工调整。 |
| 闭环可追踪 | 派发后由环卫云动态任务跟踪事件处置进度。 |

## 3. 功能详细设计
### 3.1 F01 事件接收与队列
#### 3.1.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 使话务员集中接收并处理待判别、待分配阶段的车载监控采样事件。 |
| 使用角色 | 话务员。 |
| 触发条件 | 话务员开启任务接收；接收到符合当前处理范围的事件。 |
| 功能边界 | 不承接监控中心、机器人采样、AI 监控采样、对讲机采样、无人机采样及第三方来源的事件。 |
| 成功结果 | 事件进入对应话务员队列；默认不展开详情，话务员选择事件后进入详情处理。 |
#### 3.1.2 数据与字段规则
| 展示字段 | 业务含义 | 数据来源/口径 | 空值处理 |
| --- | --- | --- | --- |
| 项目名称 | 事件所属项目。 | 上报事件。 | 待确认。 |
| 处理状态 | 话务员工作状态。枚举值：待处理、处理中、挂起中、已完成。 | 话务中心。 | 不可为空。 |
| 车牌号 | 上报车辆标识。 | 车载监控采样事件。 | 待确认。 |
| 用户名 | 上报用户/巡查员名称。 | 上报事件。 | 待确认。 |
| 上报时间 | 事件上报时间。 | 上报事件。 | 不可为空。 |
| 事件地点 | 事件标准地点。 | 上报事件。 | 待确认。 |
#### 3.1.3 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| --- | --- | --- | --- |
| Q-01 | 事件进入话务中心 | 仅接收事件来源为车载监控采样的事件；事件发现类型统一展示为人工。 | 生成或更新话务员工作项。 |
| Q-02 | 事件状态为待判别 | 事件应进入话务员待处理队列；话务员选择事件卡片或地图事件点即视为接收，并进入处理中。 | 事件：待判别；话务员：待处理→处理中。 |
| Q-03 | 话务员处理中 | 查看证据、判别、补充信息、语音沟通期间维持处理中。 | 话务员：处理中。 |
| Q-04 | 事件已派发 | 话务员工作结束；后续现场处置不再占用默认待办队列。派发成功后列表自动切换至待处理队列，不保留当前事件选择。 | 事件：待处理；话务员：已完成；当前队列：待处理；当前选中事件为空。 |
| Q-05 | 收起事件列表 | 话务员可通过左侧队列的收起按钮折叠或展开事件列表；列表不提供自动轮播或暂停轮播操作。 | 不改变队列数据、事件状态或当前选中事件。 |
| Q-06 | 切换事件卡片 | 根据当前事件关联的巡查片区，刷新该片区的模拟巡查范围、轨迹、巡查车位置、事件坐标和资源推荐数据；地图左上角显示分层的三行项目事件信息卡。 | 地图视野定位至当前片区；信息卡依次展示项目名称-项目经理名称、车牌号-关联用户-上报时间、事件地点，项目主信息与辅助信息需有清晰视觉层级；详情与资源候选数据同步至当前事件。 |
| Q-07 | 事件挂起或派发成功 | 成功后事件卡片列表自动切换至待处理队列，清空当前事件选中态，关闭详情与资源派发侧栏，地图恢复事件概览态。 | 不改变已保存的事件状态；当前队列：待处理；当前选中事件为空。 |
#### 3.1.4 交互流程
1. 话务员开启任务接收，系统加载其处理范围内的车载监控采样事件。
2. 系统按话务员工作状态归入待处理、处理中、挂起中、已完成队列，并应用第 4.2 节排序规则。
3. 默认不展开事件详情。话务员选择事件卡片或地图事件点，系统展开详情，且该选择即视为开始处理，话务员工作状态变为处理中；不设置单独的“开始处理”操作。
4. 话务员可收起左侧事件列表扩大地图视野；收起或展开不影响事件选择。选择事件卡片时，地图切换至该事件所属片区的模拟位置和业务图层。
5. 成功：列表、详情、地图和资源候选同步刷新；失败：保留当前列表并提示接收或加载失败原因。
#### 3.1.5 异常处理
| 异常场景 | 系统处理 | 用户反馈 | 恢复方式 |
| --- | --- | --- | --- |
| 无符合范围的事件 | 展示空状态。 | 提示当前暂无待处理事件。 | 保持任务接收状态，等待新事件。 |
| 事件数据加载失败 | 不改变已有队列数据。 | 提示加载失败。 | 重新加载。 |
### 3.2 F02 事件详情与判别
#### 3.2.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 让话务员依据事件原始信息和图片证据完成判别或补充信息。 |
| 使用角色 | 话务员。 |
| 触发条件 | 在事件队列中选择事件。 |
| 功能边界 | 不提供车辆运行状态检查。详情不显示顶部标题，关闭按钮悬浮于右上角且不占用内容高度；详情依次展示事件信息、事件证据、补充信息及派发信息/通话记录，不展示状态环节图或派发/通话区域标题；事件证据区仅展示原始图片或视频，不展示状态字段；事件信息展示发生时间、发现方、地点和关联任务，不展示当前状态，其中发生时间以整行等宽数字字段完整展示。详情区直接显示派发信息与通话记录标签，默认展示派发信息，可切换通话记录；派发信息仅展示处置人员、协同车辆和派发时间；通话记录仅展示时间和通话参与人，非已完成任务支持回拨，不展示通话内容。已完成任务详情为只读，隐藏补充信息操作及底部操作栏中的语音通话、派发任务、标记无效、挂起和更多操作。事件性质、类型和描述仅在补充信息表单及补充信息字段组中呈现，不展示发现类型、事件来源、经纬度或补充记录。 |
| 成功结果 | 有效事件进入待分配；无效事件直接闭环；补充信息保存至事件。 |
#### 3.2.2 数据与字段规则
| 字段 | 业务含义 | 数据来源/取值规则 | 空值处理 |
| --- | --- | --- | --- |
| 事件发生时间 | 事件实际发生或上报记录的发生时间。 | 上报事件。 | 待确认。 |
| 事件发现方 | 具体的人、车或设备，例如巡查员张三、独角兽 10032、摄像头 A。 | 上报事件。 | 待确认。 |
| 事件图片 | 事件证据图片。 | 上报事件。 | 待确认。 |
| 事件地点 | 事件标准地点。 | 上报事件。 | 待确认。 |
| 详细地点 | 具体点位或地址补充。 | 上报事件。 | 待确认。 |
| 关联任务 | 派发后关联的环卫云动态任务。 | 环卫云平台。 | 未派发时为空。 |
| 派发信息与通话记录 | 事件关联的派发信息及通话记录，通过标签切换展示。派发信息仅含处置人员、协同车辆、派发时间；通话记录仅含时间、通话参与人，非已完成任务可回拨。 | 通讯服务、资源派发及环卫云平台。 | 通话记录为空时提示暂无通话记录；派发字段暂无数据时显示 --；已完成任务不展示回拨操作；不展示通话内容。 |
| 补充信息 | 单次保存的具体补充字段。有效事件展示事件性质、事件类型、事件描述；无效事件仅展示事件性质。 | 话务员补充或图片判读。 | 未补充时提示暂无补充信息；不展示时间、来源或历史补充记录。 |
#### 3.2.3 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| --- | --- | --- | --- |
| J-01 | 查看事件详情 | 详情不显示顶部标题，关闭按钮悬浮于右上角；详情按事件信息、事件证据、补充信息、派发信息/通话记录依次展示，发生时间整行完整显示；不展示状态环节图或派发/通话区域标题。派发信息与通话记录标签直接显示，默认展示派发信息；派发信息仅展示处置人员、协同车辆、派发时间；通话记录仅展示时间与参与人，非已完成任务可回拨；事件证据和事件信息区不重复展示状态。 | 无。 |
| J-02 | 有效事件且原始描述为空 | 话务员可依据图片识别或与巡查员沟通结论补充事件性质、事件类型、事件描述。 | 更新补充字段。 |
| J-03 | 判别为有效事件 | 进入分配环节。 | 事件：待判别→待分配。 |
| J-04 | 判别为无效事件 | 补充信息弹窗隐藏问题类型和事件描述，无需填写、校验或写入这两个字段；事件流程直接闭环。 | 仅保存无效判别与闭环记录；最终事件状态口径待确认。 |
| J-05 | 保存并派发任务 | 保存有效事件的一组补充字段后，直接打开资源推荐与派发界面；补充信息卡只展示该组字段，不生成补充记录。 | 事件维持待分配，进入分配操作。 |
| J-06 | 查看已完成任务详情 | 已完成任务详情仅供查看，隐藏补充信息操作和底部操作栏，不提供语音通话、派发任务、标记无效、挂起、更多或通话记录回拨操作。 | 无。 |
#### 3.2.4 交互流程
1. 话务员进入详情后查看事件原始信息、图片、补充信息及派发信息；可直接通过派发信息、通话记录标签切换查看通话记录，并从记录回拨原参与人。
2. 话务员判别为有效事件时，可补充事件性质、事件类型或事件描述；补充结果以一组字段展示在详情中，不展示时间、来源或历史记录。有疑问时可进入沟通或挂起流程。
3. 话务员判别有效，系统校验判别结果并将事件转入待分配；可选择“保存并派发任务”直接进入资源选择。判别无效时，隐藏问题类型、事件描述和“保存并派发任务”，仅展示红色“确认闭环”以完成闭环。
4. 成功：保存补充信息并刷新详情、队列和流转信息；失败：保留已输入内容并提示失败原因。
5. 话务工作状态为已完成时，详情仅展示已留存的信息和记录，不展示任何处理操作或通话回拨入口。

| --- | --- | --- | --- | --- |

### 3.3 F03 沟通与挂起
#### 3.3.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 为信息核实和资源确认提供通话入口，并防止等待中的事件被遗漏。 |
| 使用角色 | 话务员。 |
| 触发条件 | 事件信息不清楚、需要向巡查员核实，或需要与候选资源确认。 |
| 功能边界 | 支持单人及群组语音通话；选择成员以弹窗承载，打开时默认预选当前事件的巡查上报人，其他人员限定在当前项目通讯录内并按组织分类展示、支持搜索。通话建立后以成员卡片网格承载会中管理，可继续添加或移除成员、控制单个成员麦克风、对其他成员全员静音，并可收起为地图悬浮通话条。通话结束后记录仅保存时间和通话参与人，详情及通话弹窗均可回拨原参与人；不采集或展示通话内容。车辆是否可作为通话对象仍待确认。 |
| 成功结果 | 沟通结论可用于补充事件信息或资源选择；挂起事件按提醒规则回流。 |
#### 3.3.2 数据与字段规则
| 字段 | 业务含义 | 数据来源/取值规则 | 空值处理 |
| --- | --- | --- | --- |
| 沟通对象 | 巡查员/上报人或候选人员。 | 当前事件、候选资源及通讯录。 | 至少选择一名人员；支持多选建立群组通话。 |
| 项目组织通讯录 | 当前项目内可选的沟通人员及其组织归属。 | 项目组织服务；上报人取当前事件发现方。 | 打开选择面板时默认选中巡查上报人；其他人员按组织分类展示，可按姓名、项目、组织或岗位搜索；无搜索结果时不清空已选人员。 |
| 群组成员数 | 同一通话中被选中的人员数量。 | 沟通对象选择结果。 | 至少 1 人；车辆通话能力待确认。 |
| 会中成员 | 当前正在通话的沟通对象。 | 发起通话时的已选人员，以及会中继续加入的通讯录人员。 | 移除后不再显示在当前会话；至少保留 1 名沟通对象。 |
| 麦克风状态 | 人员在当前通话内的发言状态。 | 话务员对本人或单个沟通对象的静音/解除静音操作；全员静音仅作用于其他沟通对象。 | 默认为麦克风正常；会话结束后不保留为人员固定状态。 |
| 通话记录 | 已结束通话的时间与通话参与人。 | 通讯服务在通话结束时写入。 | 无记录时提示暂无通话记录；不保存或展示通话内容；可回拨原参与人。 |
| 挂起提醒时间 | 需要再次关注该事件的时间。 | 话务员设置。 | 挂起时不可为空。 |
| 挂起时长 | 自事件进入挂起中起累计的时长。 | 系统计算。 | 不可为空。 |
#### 3.3.3 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| --- | --- | --- | --- |
| C-01 | 发起沟通 | 沟通不改变事件全流程状态；话务员工作项保持处理中；单人发起单人通话，多人发起群组通话。 | 话务员：处理中；记录参与成员。 |
| C-02 | 挂起事件 | 信息不足、等待车端回复或等待确认时可挂起；挂起成功后列表自动切换至待处理队列，不保留当前事件选择。 | 话务员：处理中→挂起中；事件保持待判别或待分配；当前队列：待处理；当前选中事件为空。 |
| C-03 | 挂起排序 | 按挂起到期/提醒时间升序，再按挂起时长降序排序。 | 队列顺序更新。 |
| C-04 | 通话进行中收起窗口 | 沟通对象默认在居中弹窗中选择；通话持续进行时，话务员可将窗口收起为地图上的悬浮通话条，并随时展开或结束通话。 | 不改变事件状态、参与成员、麦克风状态和通话计时。 |
| C-05 | 会中成员管理 | 话务员可在通话成员网格中继续添加通讯录人员或移除单个沟通对象；移除最后 1 名沟通对象时阻止操作并提示。 | 成员计数、通话成员网格和悬浮通话条名称同步更新；不改变事件状态。 |
| C-06 | 会中麦克风管理 | 话务员可对本人或单个沟通对象静音/解除静音，也可对其他沟通对象执行全员静音/解除。 | 仅更新当前会话的麦克风状态；不改变事件状态、成员关系或人员固定设置。 |
| C-07 | 查看和回拨通话记录 | 详情及通话弹窗仅展示通话时间、参与人和回拨操作；话务员点击回拨后，系统预选该条记录的参与人并打开通话选择界面。 | 不展示或保存通话内容；不改变事件状态；由话务员确认后发起新通话。 |
| C-08 | 打开通话对象选择 | 从事件详情发起通话时，系统默认选中该事件的巡查上报人；若从资源候选项发起联系，则上报人与目标资源共同预选。当前项目其他成员按组织分类展示。 | 仅加载当前项目通讯录；搜索姓名、项目、组织或岗位时实时筛选列表，不清空已选人员。 |
#### 3.3.4 交互流程
1. 话务员在事件详情或资源候选列表中打开语音通话弹窗；系统默认选中巡查上报人，并按当前项目组织展示其他人员。话务员可按姓名、项目、组织或岗位搜索后选择一名或多名沟通对象。
2. 系统按选择人数发起单人或群组语音通话，并以成员卡片网格展示当前话务员和沟通对象。
3. 通话期间，话务员可添加或移除成员，对本人或单个成员静音/解除静音，或对其他成员执行全员静音；成员数、状态和悬浮通话条名称同步刷新。
4. 话务员可将通话收起为地图悬浮通话条，再展开继续管理成员或结束通话。
5. 通话结束后系统仅写入通话时间和参与人；话务员可在详情或通话弹窗中查看记录，并通过回拨预选原参与人。
6. 话务员依据沟通结论继续补充事件信息、选择资源，或设置提醒时间将事件挂起。
7. 系统保存挂起提醒并将事件移入挂起中队列，随后自动切换事件卡片列表至待处理队列，清空当前事件选择并恢复地图概览态。
8. 成功：提示操作成功并刷新对应队列；失败：不改变原工作状态并提示失败原因。
#### 3.3.5 异常处理
| 异常场景 | 系统处理 | 用户反馈 | 恢复方式 |
| --- | --- | --- | --- |
| 未选择沟通对象 | 阻止发起沟通。 | 提示选择对象。 | 选择对象后重试。 |
| 未选择新增成员 | 阻止确认加入。 | 提示至少选择一名成员。 | 选择成员后重试。 |
| 移除最后一名沟通对象 | 阻止移除。 | 提示通话中至少保留一名沟通对象。 | 保留当前成员或直接结束通话。 |
| 未设置提醒时间即挂起 | 阻止挂起。 | 提示设置提醒时间。 | 补充提醒时间后重试。 |
| 通讯服务不可用 | 不改变事件状态和补充信息。 | 提示通讯不可用。 | 重试或改用后续确认的沟通方式。 |

#### 3.4.5 交互流程
1. 话务员对待分配事件发起分配，系统在工作台侧栏以图标返回和“资源派发”标题呈现，默认直接加载“推荐资源”标签，地图保持可见。
2. 系统按责任区域、当前距离、当前任务量的顺序排列推荐资源，并在地图展示候选位置；资源卡展示名称、任务数、岗位、距离、预计时间，并提供图标化联系、添加操作。
3. 话务员可在资源卡片或地图点位添加任意多项人员和车辆；每次添加后，资源在卡片列表下方的已选资源清单中展示，并支持移除。搜索结果与当前已选资源均在地图中保持可定位。
4. 话务员也可切换至“自主选择”，按姓名、组织、岗位或车牌搜索当前项目资源池，并按人员/车辆筛选；系统为每项已选资源展示至事件的路线预览。
5. 话务员确认派发后，系统创建动态任务并关联事件；成功后刷新事件状态和话务员队列，自动切换至待处理队列并清空当前事件选择，失败时保留选择结果并提示失败原因。

## 4. 业务规则汇总
### 4.1 事件范围与来源口径
| 规则项 | 规则 |
| --- | --- |
| 事件来源范围 | 话务中心仅处理车载监控采样事件，巡查车归入该来源。 |
| 事件发现类型 | 话务中心处理的事件统一记为人工。 |
| 非范围来源 | 监控中心、机器人采样、AI 监控采样、对讲机采样、无人机采样、第三方来源不在当前范围。 |
### 4.2 状态流转与队列排序
```text
事件：待判别 -> 待分配 -> 待处理 -> 处理中 -> 待核查 -> 已完成
话务员：待处理 -> 处理中 -> 挂起中（等待） -> 处理中 -> 已完成
有效判别：待判别 -> 待分配；分配成功：待分配 -> 待处理，话务员 -> 已完成
无效判别：事件直接闭环（最终状态口径待确认）
```
事件挂起或派发成功后，界面统一回到待处理队列，不选中任何事件，并以地图概览态展示。
| 话务员队列 | 排序规则 |
| --- | --- |
| 待处理 | 事件优先级降序，再按上报时间升序；重点项目或重点区域命中高优规则。 |
| 处理中 | 待话务员动作优先，再按长时间无更新优先，最后按开始处理时间升序。 |
| 挂起中 | 挂起到期/提醒时间升序，再按挂起时长降序。 |
| 已完成 | 按话务完成时间降序。 |
### 4.3 分配规则
| 规则项 | 规则 |
| --- | --- |
| 推荐主体 | 默认展示系统推荐资源；自主选择支持人员和车辆分类。 |
| 候选依据 | 推荐资源结合人员、车辆在线情况；自主选择的资源范围限定为当前项目可分配资源池。 |
| 排序顺序 | 责任区域 → 当前距离 → 当前任务量。 |
| 人工调整 | 资源卡展示名称、任务数、岗位、距离和预计时间，并提供图标化联系、添加操作；话务员可添加多项人员和车辆，也可切换至自主选择，按姓名、组织、岗位或车牌搜索资源。 |
| 已选清单 | 添加的资源在资源卡片列表下方以可移除清单展示；未添加资源时不可确认派发。 |
| 空间联动 | 资源派发期间地图展示事件、推荐资源、自主检索结果及当前已选资源；列表选择与地图点位双向同步，每项已选资源展示与事件的路线预览及 ETA。 |
### 4.4 数据补充与闭环规则
| 规则项 | 规则 |
| --- | --- |
| 可补充信息 | 有效事件可补充事件性质、事件类型、事件描述，并在详情中以一组具体字段展示；每个事件仅允许一次补充，不展示时间、来源或补充记录。无效事件仅需选择事件性质，不展示或写入问题类型、事件描述。 |
| 补充依据 | 事件图片识别结果或与巡查员通讯的结论。 |
| 原始描述 | 允许为空。 |
| 无效事件 | 标记为无效事件后直接闭环。 |

## 8. 验收标准
- [ ] 仅车载监控采样事件可进入话务中心；详情中的发现类型为人工、事件来源为车载监控采样。
- [ ] 事件卡片展示项目名称、话务员处理状态、车牌号、用户名、上报时间和事件地点。
- [ ] 事件详情展示本 PRD 第 3.2.2 节已确认字段，不展示状态环节图。
- [ ] 事件详情不展示顶部标题、状态环节图及派发/通话区域标题；发生时间整行完整显示；事件证据区和事件信息区不重复展示状态字段；派发信息默认展示并可切换至通话记录。
- [ ] 选择已完成任务时，详情不展示补充信息操作、派发任务、标记无效、更多、语音通话、挂起或通话记录回拨入口；已留存信息和记录仍可查看。
- [ ] 待判别事件进入话务员待处理队列，接收后变为处理中。
- [ ] 待处理、处理中、挂起中、已完成队列按第 4.2 节规则排序。
- [ ] 事件挂起或确认派发成功后，事件卡片列表自动切换至待处理队列，不选中任何事件，详情与资源派发侧栏关闭且地图恢复概览态。
- [ ] 话务员能够为有效事件补充事件性质、事件类型和事件描述，并可将事件标记为有效或无效。
- [ ] 补充信息卡仅展示一次补充的事件性质、事件类型、事件描述等具体字段，不展示时间、来源或补充记录。
- [ ] 选择无效事件后，补充信息弹窗不展示问题类型和事件描述，保存时不写入这两个字段并完成闭环。
- [ ] 无效事件执行直接闭环；最终事件状态按确认后的口径保存。
- [ ] 话务员能够在弹窗中选择一名或多名人员发起单人或群组语音通话；通话中以成员卡片网格展示，支持继续添加、移除、单人静音/解除静音和其他成员全员静音；通话可收起为地图悬浮通话条，并可设置挂起提醒。
- [ ] 从事件详情打开通话对象选择时，当前巡查上报人默认已选；其他可选人员按当前项目组织分类展示，支持按姓名、项目、组织或岗位搜索，搜索筛选不清空已选人员。
- [ ] 资源派发侧栏顶部展示返回事件详情图标与“资源派发”标题；内容区直接展示“推荐资源”“自主选择”标签，不展示当前事件、推荐处置人员或自主选择说明卡片。
- [ ] 资源派发按责任区域、当前距离、当前任务量排序展示系统推荐；资源卡展示名称、任务数、岗位、距离和预计时间，并以图标提供联系、添加操作；话务员可切换至自主选择，按姓名、组织、岗位或车牌搜索当前项目可分配的人员或车辆资源，且无结果不清空已选资源。
- [ ] 人员和车辆均支持多选；添加的资源在卡片列表下方以可移除清单展示。派发期间地图持续展示事件、推荐资源、自主检索结果和每项已选资源至事件的路线预览及 ETA，列表与地图点位可双向选择。
- [ ] 分配成功后，事件转为待处理、话务员工作项转为已完成，并在环卫云生成关联动态任务。
- [ ] 派发信息仅展示处置人员、协同车辆和派发时间，不展示派发状态、任务状态、待派发/待判别信息或说明文字；关联任务在事件信息区展示。
- [ ] 详情与通话弹窗中的通话记录仅展示时间和通话参与人，不展示通话内容；话务员可从任一记录回拨，系统预选原参与人后进入通话选择界面。
- [ ] 默认进入工作台时，所有事件卡片与地图事件点均未选中；地图仅展示可点击事件点，不显示事件摘要、巡查车当前位置、巡查轨迹或巡查上报范围。
- [ ] 选中事件卡片或地图事件点后，地图加载对应事件的摘要、巡查车当前位置、巡查轨迹和巡查上报范围；地图容器不加载 SVG 覆盖图形。
- [ ] 左侧事件列表可收起和展开，且页面不存在事件轮播或暂停轮播操作。
- [ ] 切换不同巡查片区的事件卡片时，地图位置、事件点、巡查车位置、轨迹、上报范围及资源推荐模拟数据随当前事件同步切换。
