## 一、设计原则

1. **移动优先（Mobile First）**：所有组件与布局以 375px 为基础视口设计，向上适配至 414px、768px。
2. **单手操作友好**：高频操作区域集中在屏幕下半部，避免顶部死角。
3. **信息层级清晰**：通过字号、字重、色彩、留白区分主次信息。
4. **反馈即时**：任何用户操作均需提供视觉或动效反馈。
5. **一致性**：同一款产品内，相同场景使用相同组件与交互模式。

## 四、布局与栅格

### 4.1 基础视口

- **设计基准宽度**：375px
- **最大内容宽度**：430px（大屏手机居中显示）
- **水平边距**：16px（通用），12px（紧凑场景）
- **模块间距**：8px、12px、16px、24px，以 4px 为基准单位

### 4.2 安全区

| 区域 | 高度 | 说明 |
|:---|:---|:---|
| 顶部状态栏 | 20–44px | 由系统决定，内容不侵入 |
| 顶部导航栏 | 44px | 页面标题 + 左右操作 |
| 底部安全区 | 20–34px | 适配刘海屏手势条 |
| 底部 Tab 栏 | 56px（含安全区） | 主导航固定底部 |

### 4.3 栅格

- 移动端采用 **单列流式布局**，不使用 24 栅格。
- 内容区宽度 = 视口宽度 − 32px（左右各 16px）。
- 双列卡片间距 12px，单列卡片全宽。

## 五、导航规范

### 5.1 顶部导航栏

- 高度 44px，背景 `#ffffff`，底部 1px 分割线 `#e8e8e8`。
- 左侧：返回按钮（`<` 图标）或关闭按钮。
- 中间：页面标题，16px Semibold，居中。
- 右侧：文字操作或图标操作（如筛选、更多）。
- 固定定位 `position: fixed; top: 0; z-index: 1000`。

### 5.2 底部 Tab 导航

- 高度 56px（不含安全区），背景 `#ffffff`，顶部 1px 分割线 `#e8e8e8`。
- Tab 项：图标 + 文字，图标 24px，文字 10px。
- 选中态：主色 `#1677ff`。
- 未选中态：次要文字色 `#00000073`。
- 固定定位 `position: fixed; bottom: 0; z-index: 1000`。

## 六、组件规范

### 6.1 按钮

| 类型 | 高度 | 圆角 | 字号 | 字重 | 说明 |
|:---|:---|:---|:---|:---|:---|
| 主按钮 | 44px | 8px | 16px | Medium | 背景主色，白色文字 |
| 次按钮 | 44px | 8px | 16px | Medium | 白色背景，主色边框 |
| 文字按钮 | 32px | — | 14px | Medium | 主色文字，无背景 |
| 小按钮 | 28px | 4px | 12px | Regular | 用于列表内操作 |
| 底部固定按钮 | 44px | 8px | 16px | Medium | 距左右 16px，距底部 16px + 安全区 |

- 按钮点击态：透明度 0.85 或背景加深。
- 禁用态：背景 `#85a5cc` 或文字 `#00000040`，不可点击。
- 同一页面主按钮不超过 1 个。

### 6.2 表单

#### 6.2.1 表单布局

- 移动端采用**顶部标签 + 下方输入框**布局。
- 标签 14px Regular，必填项标签前加红色星号 `*`。
- 输入框高度 44px，圆角 8px，内边距 0 12px。
- 表单项垂直间距 16px。

#### 6.2.2 输入框

- 背景 `#ffffff`，边框 1px `#e8e8e8`。
- Focus 态：边框主色 `#1677ff`，外发光 0 0 0 2px `#e6f4ff`。
- Error 态：边框错误色 `#ff4d4f`。
- 占位符颜色 `#00000040`。

#### 6.2.3 选择器

- 触发区域与输入框同高同宽。
- 底部弹出选择面板（ActionSheet/Picker），遮罩 50% 黑色。
- 选中项高亮主色，右侧打勾图标。

#### 6.2.4 时间选择器

- 默认底部弹出。
- 日期格式：`YYYY-MM-DD`；时间格式：`HH:mm`。
- 支持「确认/取消」操作。

#### 6.2.5 校验与错误提示

- 错误提示位于输入框下方，12px 错误色文字。
- 提交时自动滚动到第一个错误项。
- 实时校验可在失焦（blur）时触发。

### 6.3 列表

#### 6.3.1 卡片列表

- 卡片背景 `#ffffff`，圆角 12px，内边距 16px。
- 卡片间距 12px。
- 卡片阴影：0 2px 8px rgba(0,0,0,0.04)。
- 状态标签：圆角 4px，内边距 2px 8px，12px 字号。

#### 6.3.2 普通列表

- 行高 48–56px。
- 左侧图标/头像 40px，右侧箭头或操作。
- 分割线：左侧缩进 16px，1px `#e8e8e8`。

### 6.4 图片上传

- 上传按钮：96px × 96px，圆角 8px，边框 1px 虚线 `#d9d9d9`。
- 内部：相机图标 24px + 辅助文字 12px。
- 已上传图片：96px × 96px 缩略图，右上角删除按钮 20px。
- 仅拍照场景：点击直接调起相机。
- 拍照失败/权限拒绝：Toast 提示 + 设置引导。

### 6.5 弹窗

#### 6.5.1 确认弹窗

- 宽度 280px，圆角 16px。
- 标题 16px Semibold，居中。
- 内容 14px Regular，居中，最大 2 行。
- 按钮：左取消（文字按钮/次按钮），右确认（主按钮）。

#### 6.5.2 底部弹窗

- 底部弹出，圆角 16px（仅顶部圆角）。
- 用于筛选、选择器、更多操作。
- 标题栏高度 48px，含关闭按钮。

### 6.6 Toast

- 背景 `rgba(0,0,0,0.7)`，圆角 8px。
- 文字 14px，白色。
- 位置：屏幕垂直居中。
- 自动消失 2–3 秒，成功/错误/加载三种类型。
- 加载类型可带转圈图标。

### 6.7 Loading

- 页面级：全屏遮罩 + 转圈图标 + 提示文字。
- 按钮级：按钮内显示转圈，文字替换为「提交中…」。
- 骨架屏：列表加载时使用，灰色块模拟内容。

## 七、交互与状态

1. **点击反馈**：按钮、列表、卡片点击时瞬时降低透明度或背景变深。
2. **加载状态**：网络请求期间显示 Loading，避免重复提交。
3. **空状态**：列表为空时显示插画 + 说明文字 + 操作按钮（如有必要）。
4. **下拉刷新**：列表顶部下拉触发刷新，显示加载动画。
5. **上拉加载**：列表底部上拉加载更多，显示「加载中…/没有更多了」。
6. **返回保存**：表单页返回时，若已填写内容，提示「是否保存草稿」。

## 八、响应式与适配

| 视口宽度 | 适配策略 |
|:---|:---|
| 320–375px | 基准布局，内容区 16px 边距 |
| 376–414px | 等比放大间距，按钮/输入框保持 44px 高度 |
| 415–768px | 内容区最大宽度 430px，居中显示 |
| ≥769px | 按移动端大屏居中展示，或切换为 PC 布局（如项目需要） |

- 图片上传、按钮等组件尺寸不随屏幕等比放大。
- 字体大小不随屏幕缩放，保持可读性。

***

## 九、技术栈与代码规范

1. **技术栈**：`HTML5 + Tailwind CSS v3 + 原生 JavaScript`。
2. **移动端适配**：采用 `viewport` + `rem` 或 `flexible` 方案，设计稿按 375px 输出。
3. **结构**：语义化 HTML，公共组件（导航栏、底部 Tab）单独抽离复用。
4. **输出**：
   - 每个页面独立 HTML 文件。
   - 页面尺寸按 iPhone 比例设计，便于在浏览器中模拟预览。
   - 附带页面用途、核心功能、交互逻辑说明。

***

## 十、额外约束

- 仅实现静态交互（弹窗、跳转用 `#` 锚点），无需后端接口。
- 所有颜色、尺寸、间距必须写死或用 Tailwind 类控制，禁止无规则的 margin/padding。
- 生成后需检查：375px、414px、768px 三种宽度下无布局错乱、按钮无溢出、表单无遮挡。
- 与具体业务需求解耦：本规范为通用移动端 APP 规范，各业务页面在此基础上按需裁剪组件。
