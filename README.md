# 运营中心与话务中心高保真原型
## 入口
- 根目录 `index.html` 会自动跳转至运营中心框架页。
- `03-高保真页面/运营中心框架.html`：复刻运营中心顶栏与左侧业务导航，在“处理体系”和“监督考核”之间新增“品质运营”，提供“运营调度”和“调度记录”两个子模块。
## 页面清单
- `03-高保真页面/话务中心/话务中心工作台.html`：话务员事件接收、判别、沟通、挂起与任务派发主流程，支持收起事件队列，并按当前事件切换区域巡查地图和资源模拟数据；地图右上角提供巡查员来电请求入口，支持事件关联型与普通来电、多条请求、类型筛选、弹层自动收起、60秒超时和单通话互斥。来电卡片固定展示来电类型、来电人名称或车牌号、所属项目、来电时间；来电请求列表提供统一通话记录入口，汇集事件呼入、事件外呼与普通通话，支持独立维度筛选、分页和事件联动。事件来电接听后自动定位关联事件，并仅在需要时挂起当前前台事件；普通来电不改变事件处置状态。接听来电后复用既有通话弹窗与地图悬浮通话条，默认收起，点击“展开”继续管理通话。资源派发复用工作台右侧栏，推荐资源默认选中并允许移除，已选资源置顶展示；所有资源筛选组统一提供搜索、人员/车辆、“显示在线”和派发范围，“显示在线”默认勾选，并支持输入或拖动地图范围圆调整默认 300m 的候选范围；地图右上角不再提供当前项目在线人员开关。群组通话支持成员与麦克风管理。事件图片预览提供补充信息、派发任务和标记无效操作；已完成任务详情保持只读。
- `03-高保真页面/话务中心/后台任务明细.html`：从工作台右上角“后台管理”进入的事件记录明细后台页，首屏直接提供查询和列表操作，支持按项目名称、车牌号、关联巡查员、话务员、发生时间范围、接单时间范围和处理状态查询；条件超出一行时默认收起并可展开更多条件，查询、重置和导出操作始终同一行。列表支持勾选、分页、导出所选记录，并展示接单时间；详情弹窗可查看事件、补充和派发信息，以及位于右侧、按事件顺序排列的结构化操作时间轴（日期、时间、操作人、操作行为）。
- `03-高保真页面/话务中心/高优规则配置.html`：后台高优规则配置页，从后台导航进入。高优规则分为“重点项目”与“重点问题类型”两个维度清单，事件命中任一维度即判定为高优先级（OR 逻辑），在待处理、处理中、挂起中队列中优先排序；未命中的事件为普通优先级。两维度清单支持添加、删除、恢复默认，配置写入本地存储，工作台加载时按配置自动重算存量事件。
- `03-高保真页面/话务中心/无待办事件.html`：暂无待处理事件的空状态。
- `03-高保真页面/话务中心/派发处理中.html`：任务派发等待状态。
## 运营中心嵌入
- “运营调度”通过 iframe 加载 `话务中心/话务中心工作台.html?embed=1`，隐藏话务中心重复顶栏并保留事件队列、地图、详情、通话、派发等交互。
- “调度记录”通过 iframe 加载 `话务中心/后台任务明细.html?embed=1`，隐藏后台页重复顶栏与内层侧栏并保留筛选、列表、分页和详情时间轴。
- 工作台、后台明细均支持 `?embed=1` 内容区模式；不带参数时仍可独立打开，原有页面跳转保持有效。
## 公共组件
- `03-高保真页面/话务中心/assets/common.css`：公共 Ant Design 风格变量、头部、按钮、标签、弹窗和表单样式。
- `03-高保真页面/话务中心/assets/common.js`：弹窗和提示的静态交互。
- `03-高保真页面/话务中心/assets/vendor/leaflet/`：本地 Leaflet 地图库，用于事件点选、巡查车位置、巡查轨迹、巡查上报范围和地图缩放；底图通过 OpenStreetMap 在线瓦片加载，因此预览环境需要可访问互联网。
## 最近变更
- 2026-10-15：基于来电请求升级统一“通话记录”，汇集事件呼入、事件外呼和普通通话；通话方向、业务关联、结果独立展示与筛选，多人对象直接显示姓名，记录时长统一使用 min，支持通话对象模糊查询、起止日期范围筛选、分页和连续完整列表；记录可跳转关联事件或按现有权限回拨，事件详情与通话弹窗共用记录；超时未接自动留存，普通回拨不关联前台事件，已完成事件保持只读。原型使用示例数据和当前页面会话数据，刷新后恢复示例。
- 2026-09-08：任务派发合并推荐资源与自主选择，推荐资源默认加入顶部已选清单；所有资源筛选组统一提供搜索、人员/车辆、“显示在线”和默认 300m 的可输入、可拖动派发范围；移除地图右上角当前项目在线人员开关。
- 2026-09-04：运营调度地图右上角新增巡查员来电请求，支持事件来电与普通来电；来电卡片仅展示项目、车牌号、巡查员和请求时间，暂不支持跨页面来电。
- 2026-09-05：优化来电请求卡片字段，新增历史通话记录按钮和记录弹窗。
- 2026-09-05：历史通话记录增加通话时长、来电类型和时间范围筛选，记录按日期分组并支持折叠与内部滚动。
- 2026-09-04：运营中心框架移除品质运营下的“规则配置”模块入口，仅保留“运营调度”和“调度记录”；独立高优规则配置页及后台入口保持不变。
- 2026-08-13：队列新增全局轻量搜索（项目、巡查员、车牌模糊匹配）与时间范围快捷筛选（近3天/近7天/全部，默认近3天，挂起中豁免窗口，搜索突破窗口）；事件卡片时间显示增加日期（月-日 时:分）；补充信息与预览补充信息在标记无效时补齐无效原因与处置说明，与标记无效按钮口径统一；新增后台“高优规则配置”页（重点项目/重点问题类型两维度清单，任一命中即高优，存量事件自动重算）；任务派发面板由“资源派发”更名；自主选择中车辆卡片不展示岗位与通话入口；队列头部移除排序说明与条数，收起按钮移至列表右缘；事件卡片支持再次点击取消选中并恢复地图全点位。
- 2026-08-10：待处理事件改为由话务员显式点击“开始处理”接单；接单后将处理人和接单时间集成到事件信息标题，才开放后续处理操作。挂起事件继续归原处理人，直接保留补充、通话、派发和无效闭环入口，不再设置恢复处理按钮；未接单事件的图片预览仅支持查看。本版本不支持话务员间移交或释放。后台事件记录明细新增发生时间、接单时间范围筛选与接单时间列表字段；查询条件在空间不足时默认折叠为一行并支持展开，导出操作移至查询操作行。
